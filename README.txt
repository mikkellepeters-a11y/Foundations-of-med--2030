START HERE
1. Keep this entire folder together.
2. Open Terminal.
3. Type: cd 
   Then drag this folder into Terminal and press Return.
4. Run:
   python3 -m http.server 8000 --bind 127.0.0.1
5. Open:
   http://localhost:8000
6. Stop the local server with Control-C when finished.

Using localhost keeps the quiz pages on one shared browser origin so progress,
scores, and the Highly Missed & Filed for Review bank can work consistently.
The site remains local to your computer.
