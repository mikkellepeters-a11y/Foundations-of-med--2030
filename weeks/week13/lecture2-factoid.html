Overview of the Nervous System and Spinal Cord — Factoid Sheet

MSK–Skin · Week 13 · Lecture 2 · Rapid pre-exam retrieval · Lecture slides + accompanying handout
Master framework: CNS/PNS → spinal cord landmarks → roots versus rami → dermatomes/myotomes → meningeal spaces and procedures → vessels and clinical deficits.

CNS / PNS / modality

  • CNS = brain + spinal cord
  • PNS = cranial/spinal nerves + ganglia
  • Afferent = toward CNS; efferent = away
  • Somatic = body wall/limbs; visceral = organs
  • Nucleus/tract = CNS; ganglion/nerve = PNS

Neuron morphology / glia

  • Multipolar = motor and interneurons
  • Pseudounipolar = general sensory; cell bodies in DRG
  • Bipolar = special sensory (retina, olfactory)
  • CNS glia: astrocyte, oligodendrocyte, ependymal, microglia
  • PNS glia: Schwann, satellite

Cord landmarks

  • Foramen magnum → adult conus at L1/L2
  • Cauda equina = trailing lumbar/sacral roots
  • Filum terminale = anchoring connective tissue
  • Posterior median sulcus = shallow; anterior median fissure = deep
  • 31 pairs: 8C / 12T / 5L / 5S / 1Co

Gray vs white matter

  • Dorsal horn = sensory input processing
  • Ventral horn = lower motor cell bodies
  • Lateral autonomic column = visceral motor neurons
  • Posterior funiculus = ascending sensory
  • Anterior / lateral funiculi = ascending sensory + descending motor
  • White matter generally increases toward the cervical cord

Roots vs rami — do not confuse

  • Dorsal root = sensory only; DRG cell bodies
  • Ventral root = motor only
  • Spinal nerve = mixed
  • Dorsal ramus = mixed; intrinsic back + skin
  • Ventral ramus = mixed; trunk/limbs, plexuses
  • Ventral root ≠ ventral ramus

Vertebrae, exits and discs

  • C1–C7 nerves exit above same-number vertebra
  • C8 exits between C7/T1
  • T1 onward exit below same-number vertebra
  • L4–L5 posterolateral disc → L5 root
  • L5–S1 → S1 root
  • C5–C6 → C6; C6–C7 → C7 (handout)

Dermatome vs cutaneous nerve

  • Dermatome = one spinal nerve/root-associated unilateral segment
  • Peripheral cutaneous nerve = often many root inputs after plexus mixing
  • T4 nipple · T7 xiphoid · T10 umbilicus
  • Zoster: latent VZV in sensory ganglion → unilateral dermatomal painful vesicles

Motor / reflex

  • Myotome = root-associated muscle group/action
  • C5 → axillary nerve → deltoid → arm abduction
  • Reflex arc: receptor → sensory neuron → cord → motor neuron → effector
  • Stretch reflex: tendon tap → muscle stretch → contraction

Meninges / spaces

  • Outside → inside: epidural → dura → potential subdural → arachnoid → subarachnoid CSF → pia
  • Epidural: fat + vertebral venous plexus
  • Subarachnoid: CSF, spinal vessels
  • Pia: denticulate ligaments, filum internum
  • Dural sac: to ~S2 (handout)

Lumbar puncture vs epidural

  • LP: L3–L4 / L4–L5, iliac crests ~L4, CSF sample
  • Skin → subcutis → supraspinous → interspinous → flavum → epidural → dura → arachnoid → CSF
  • Epidural: medication deposited outside dura
  • Slide includes possible muscle step; midline handout omits it

Arteries

  • 1 anterior spinal artery → anterior 2/3
  • 2 posterior spinal arteries → posterior 1/3
  • Segmental medullary arteries reinforce blood flow
  • Adamkiewicz = major lower-cord reinforcement; left in ~65% per slide; aortic surgical relevance

Veins / emergencies

  • Spinal veins → internal epidural vertebral plexus
  • Batson plexus valveless → metastatic/infectious route
  • Cauda equina red flags: urinary retention, saddle anesthesia, bowel/bladder dysfunction, multiroot weakness → emergency evaluation
  • Radiculopathy: root pain ± sensory/motor/reflex deficit

FIRST AID RAPID CONNECTIONS

  1. VZV sensory ganglion latency → unilateral painful dermatomal vesicles.
  2. Root injury → radicular sensory disturbance ± weakness and altered reflex.
  3. Cauda equina compression → saddle anesthesia + bladder/bowel red flags.
  4. Anterior spinal artery ischemia → motor + pain/temperature deficits, relative posterior column sparing.
  5. UMN disruption can produce hyperreflexia; an interrupted peripheral reflex arc can reduce reflexes.
