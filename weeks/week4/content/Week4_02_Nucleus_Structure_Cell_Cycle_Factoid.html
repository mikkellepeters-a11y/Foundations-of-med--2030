Nuclear Transport

Small cargo
Roughly <40 kDa can cross more freely by diffusion.
Large cargo
NLS/NES + karyopherin (importin/exportin) + Ran-GTP cycle.
Import sequence: NLS cargo binds importin alpha/beta → pore transit → Ran-GTP promotes cargo release → receptors recycle; RanGAP converts Ran-GTP to Ran-GDP in cytoplasm.

Mitosis Trigger

MPF = cyclin B + CDK1. Drives chromosome condensation, lamin phosphorylation/nuclear-envelope breakdown, spindle formation, and organelle fragmentation.

How Activity Is Controlled

Cyclins
Concentration changes; ubiquitin-proteasome degradation.
CDKs
Cyclin binding + activating/inhibitory phosphorylation; CKIs such as p21 block activity.

Rb Restriction Point

Unphosphorylated Rb = active brake. It sequesters E2F. Growth-factor signaling activates cyclin D/CDK4/6 → Rb phosphorylation → Rb inactive → E2F released → S-phase genes expressed.

CDK4/6 Inhibition

Block CDK4/6 → less Rb phosphorylation → Rb remains active → E2F remains restrained → G1-S progression slows/stops.

Growth Factor to S Phase

Growth factor → receptor / signal-transduction cascade (e.g., Ras-pathway kinase signaling) → increased cyclin D/CDK4/6 activity → Rb phosphorylation/inactivation → E2F release → S-phase transcription.

Must-Not-Miss Traps

Lamins = intermediate filaments.
Cyclin B/CDK1 = MPF.
Phosphorylated Rb = inactive.

30-Second Review

NLS/importins/Ran for large nuclear import. Nucleolus builds ribosomal components. LMNA disease can create progerin. Cyclins rise/fall; CDKs are switched by binding/phosphorylation. D-CDK4/6 phosphorylates Rb; E2F is released; S phase follows.
