Gene-Expression Language

Cis = local DNA/RNA sequence: promoter, enhancer, silencer/operator, response element.
Trans = diffusible protein/ncRNA: TF, activator, repressor, coactivator, miRNA, lncRNA.

Estrogen Receptor

Type I nuclear receptor: estrogen binds intracellular ER → dimerization/nuclear entry → ERE binding → coactivator-mediated transcription. Tamoxifen blocks the productive coactivator conformation.

X-Inactivation

XIST coats one X → hypermethylation + histone deacetylation → Barr body. Random selection creates mosaicism. Some genes, especially pseudoautosomal genes, escape.

Must-Not-Miss

Cis = sequence; trans = factor. Lactose removes the brake, low glucose adds the accelerator. HAT opens. DNA methylation usually silences. PWS paternal / AS maternal. HTH-HLH-zipper-zinc finger. miRNA/siRNA use RISC. XIST silences X.
