CBC, Differential, & Peripheral Blood Smear

Week 2 SAL · Factoid Sheet · current lecture scope
Reading order: CBC question → identify cell line → if WBC, calculate absolute count; if RBC, Hgb/Hct → MCV → MCH/MCHC → RDW → retics → smear; if platelets, exclude artifact before labeling disease.

CBC vs Diff

CBC: WBC, RBC, Hgb, Hct, indices, platelets.

Diff: neutrophils, lymphocytes, monocytes, eosinophils, basophils.

Do not reflexively repeat a Diff when WBC is normal and there is no WBC concern.

Absolute count

Absolute count = WBC × fraction

Example: 2.7 × 0.37 = 0.999 ≈ 1.0 ×10⁹/L.

Absolute count is more clinically useful than percentage alone.

Normal RBC

~7 μm, biconcave, central pallor ~1/3 diameter.

>1/3 pallor → hypochromia. Smaller than 7 μm → microcytic.

Reticulocyte response

Lecture frame: <2% = non-compensated; >3% = compensated.

High response: blood loss, hemolysis, regeneration/corrected deficiency.

Anemia by MCV

Micro: iron deficiency, ACD, thal/hemoglobinopathy.

Normo: blood loss, ACD, hemoglobinopathy.

Macro: nutritional, meds/toxins, thyroid, liver, reticulocytosis.

Hemolysis

↑ LDH + ↓ haptoglobin.

Intrinsic: membrane, Hb/thal, enzyme, PNH.

Extrinsic: infection, immune, MAHA, drugs/toxins, cirrhosis.

Platelets

PatternLecture clues
NormalBlue-gray fragments; 1.5-3 μm; fine alpha granules; typical 150-400K.
ThrombocytosisUsually reactive: trauma, infection, iron deficiency, hyposplenism, inflammation.
Worry in thrombocytosisPersistent without cause, immature cells, basophilia, unusual morphology.
PseudothrombocytopeniaClot, platelet clumps, fibrin strands, satellitism.

Emergency pattern: anemia + thrombocytopenia + schistocytes → MAHA differential: HUS, aHUS, TTP, DIC, malignant HTN, mechanical, HELLP.

Last-minute discriminators

  1. High RDW = anisocytosis.
  2. Reactive lymphocytes: heterogeneity + CBC data + clinical setting.
  3. Basophilia is a red flag for myeloproliferative disease.
  4. Spherocyte = no central pallor; schistocyte = fragment.
  5. Before diagnosing low platelets, look for clumping/artifact.
  6. Pancytopenia severity/number of lines increases concern for marrow replacement, but benign causes are broad.
