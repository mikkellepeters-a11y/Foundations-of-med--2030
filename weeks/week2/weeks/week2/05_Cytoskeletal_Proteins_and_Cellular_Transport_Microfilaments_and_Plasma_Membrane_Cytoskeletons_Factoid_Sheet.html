Microfilaments & Plasma Membrane Cytoskeletons

Week 2 · Core 05 · Factoid Sheet · current lecture scope
Automatic discriminator: Formin = linear actin. Arp2/3 = branched actin.

Actin basics

  • Actin = smallest major cytoskeletal filament; enriched at cortex.
  • G-actin monomers polymerize into F-actin.
  • Actin binds ATP.
  • Barbed (+) end grows faster; pointed (-) end favors loss.

Architecture

  • Formins nucleate/elongate straight filaments.
  • Profilin delivers ATP-ready G-actin to formins.
  • Arp2/3 makes branched networks from existing filaments.
  • WASP-family proteins activate Arp2/3.

Actin dynamics

  • Phalloidin binds/stabilizes F-actin.
  • Cytochalasin D caps (+) end → net breakdown.
  • Migration/phagocytosis need ongoing assembly + disassembly.

Actin + myosin

  • Myosin = ATP-powered actin motor.
  • Cytokinesis uses actin-myosin contractile ring.
  • Muscle contraction uses thin actin + thick myosin filaments.

Pathogens + disease

  • Listeria: recruits host Arp2/3 machinery → actin comet tail → intracellular movement/cell-to-cell spread.
  • Wiskott-Aldrich syndrome protein: branched-actin regulator with Arp2/3; X-linked; immune-cell motility/phagocytic capacity affected.
  • Profilin: required for actin assembly; some AD mutations associated with ALS; mechanism presented as unresolved.

Membrane cytoskeleton + context

RBC framework: spectrin tetramers + short actin make the lattice; ankyrin and Band 3-associated proteins help connect it to the membrane.
ConditionStructural defect / result
Hereditary spherocytosisWeakened membrane-skeleton attachment → membrane loss → round, less deformable RBCs → splenic trapping, hemolytic anemia, splenomegaly.
Hereditary elliptocytosisUsually spectrin/lattice defects → elongated RBCs; generally milder in the lecture.
Duchenne muscular dystrophyDystrophin defect weakens linkage between intracellular actin and membrane/ECM support → repeated contraction damages muscle.

Intermediate filaments: secondary lecture context

  • Coiled-coil, rope-like, stable, and nonpolar after assembly.
  • Keratins = epithelia; vimentin = connective tissue; neurofilaments = neurons; lamins = nuclear envelope.
  • Current lecture examples: keratin-associated epidermolysis bullosa; Lamin A/C-associated progeria, muscular dystrophy, and cardiomyopathy.

Six test-ready discriminators

  1. Actin uses ATP; tubulin uses GTP.
  2. Formin = straight; Arp2/3 = branched.
  3. Microvilli = stable absorption; filopodia = dynamic sensing; lamellipodia = branched migration.
  4. Phalloidin stabilizes; cytochalasin D drives breakdown by capping the + end.
  5. RBC membrane support = spectrin/actin/ankyrin/Band 3 framework.
  6. Dystrophin links muscle actin to membrane/extracellular support.
