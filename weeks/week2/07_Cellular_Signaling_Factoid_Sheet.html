Cellular Signaling

Week 2 · Core 07 · Factoid Sheet · objective-driven rapid review
GPCR switch
GPCR (GEF) → GDP out / GTP in → G protein ON
GTPase + GAP → GTP→GDP → OFF
  • GDP-bound Gα = inactive.
  • GTP-bound Gα = active.
  • More GEF → stronger signaling; more GAP/GTPase → faster shutoff.

ProteinCore pathway

GPCR desensitization
  • GRK phosphorylation + arrestin → uncoupling/desensitization.
  • Internalization → recycling or degradation.
  • Phosphodiesterases degrade cyclic nucleotides.
  • Phosphatases reverse phosphorylation; Ca²⁺ is resequestered.
PLC pathway
Gαq → PLC → PIP2 → DAG + IP3
  • IP3 → ER Ca²⁺ release.
  • Ca²⁺/calmodulin can activate MLCK.
  • DAG contributes to PKC activation.
Smooth-muscle contraction
Gq → Ca²⁺/CaM → MLCK → MLC-P → contraction
G12/13 → RhoA/ROCK → MLCP inhibition → contraction
MLCK = contract. MLCP = relax.
Photoreception
Light → rhodopsin → transducin → PDE6 → cGMP ↓
  • Cyclic-nucleotide-gated Na⁺/Ca²⁺ channels close.
  • Rod hyperpolarizes.
  • Glutamate release falls.
  • Sample-question answer: cGMP is converted to GMP.
Cholera
CT → ADP-ribosylates Gαs → AC stays active → cAMP ↑
PKA ↑ → CFTR Cl⁻ secretion ↑ → Na⁺/H₂O follow → watery diarrhea

Pertussis comparison: loss of Gαi inhibition also raises cAMP.

NO / cGMP / PKG
NO → sGC → cGMP → PKG
  • PKG decreases contraction signaling.
  • PKG activates MLCP and reduces Ca²⁺-dependent contraction.
  • Net: vascular smooth-muscle relaxation.

Drugs + growth-factor pathways

Stable angina / vasodilation
  • Nitroglycerin and nitroprusside feed the NO pathway.
  • More NO → more cGMP/PKG → vasodilation.
Erectile dysfunction
  • PDE5 degrades cGMP.
  • PDE5 inhibitors preserve cGMP → prolong smooth-muscle relaxation.
PDE5 inhibitor + nitrate = contraindicated in the lecture because of excessive hypotension.
Ras-MAPK
RTK → Grb2/SOS → Ras → Raf → MEK → ERK → proliferation
PI3K-AKT
RTK → PI3K → PIP3 → PDK/AKT
  • Survival / blocks apoptosis
  • Protein synthesis
  • Metabolic effects
  • PTEN opposes PIP3 signaling.
Wnt / β-catenin
  • Wnt OFF: β-catenin targeted for destruction.
  • Wnt ON: β-catenin stabilized → transcription.
  • Lecture labels include cyclin D1 and c-MYC.
Cancer logic
  • Growth-factor pathways are common mutation targets.
  • Activating mutations can affect positive components (KRAS, PI3K, EGFR).
  • Inactivating mutations can remove brakes (PTEN).
  • Advanced tumors often contain multiple accumulated alterations.
