Plasma Lipid Transport — Lipoproteins - Factoid Sheet

Week 3 • Tuesday Lecture 7 • current deck primary
Master map: FFA travels on albumin • dietary long-chain lipid → chylomicron • hepatic lipid → VLDL → IDL → LDL • HDL retrieves peripheral cholesterol.

Lipoprotein Structure / Density

Core
TG + cholesterol esters.
Surface
Phospholipids + free cholesterol + apolipoproteins.
Density rule: more protein / less TG = higher density. Chylomicron → VLDL → IDL → LDL → HDL.

Apolipoproteins & Enzymes

ProteinFunction
ApoA-IHDL structural protein; activates LCAT.
ApoB-48Structural protein for intestinal chylomicrons.
ApoB-100VLDL/IDL/LDL structural protein; LDL-receptor ligand.
ApoC-IIActivates LPL.
ApoEHepatic uptake of remnants.
LPLEndothelial TG hydrolysis in chylomicrons/VLDL.
MTTPTransfers lipid onto ApoB during chylomicron/VLDL assembly.

Exogenous vs Endogenous

PathwaySequence
Dietary / exogenousIntestine → chylomicron (ApoB-48) → HDL donates C-II/E → LPL removes TG → remnant → liver via ApoE.
EndogenousLiver → VLDL (ApoB-100) → LPL → IDL → hepatic clearance via ApoE or further processing → LDL → LDL receptor via ApoB-100.

Lipoproteins — HDL + Disease

Reverse Cholesterol Transport

ApoA-I → ABCA1/ABCG1 lipidation → LCAT esterifies cholesterol → HDL matures → SR-B1 direct hepatic delivery and/or CETP exchange with ApoB particles.

Defect Patterns

DefectPattern
MTTPAbetalipoproteinemia: no effective chylomicron/VLDL assembly → fat malabsorption, very low ApoB particles.
LPL / ApoC-IIExtreme TG-rich particle accumulation; pancreatitis risk.
LDL receptor / ApoB-100High LDL / familial hypercholesterolemia pattern; premature atherosclerosis.
ApoERemnant accumulation (chylomicron remnants + IDL).
Secondary AI-note enrichment: oxidized LDL is taken up by macrophage scavenger receptors → foam cells; Lp(a) adds apo(a), which resembles plasminogen and can impair fibrinolysis.
