Faculty caveat: mechanisms overlap clinically. Exams ask for the predominant mechanism.

Allergy / atopy

  • Allergy in the deck's preferred US usage = IgE-dependent Type I mechanism, not a disease/diagnosis.
  • Classic “atopic diseases” = rhinitis + asthma + atopic dermatitis; inherited together (“atopic march”).
  • Non-IgE biology exists: epithelial TSLP → ILC2; tezepelumab targets TSLP.
  • Chronic urticaria is very rarely IgE-dependent; FcεRI autoantibody can activate mast cells.

Type I trigger

IgE-FcεRI waits → allergen cross-links IgE → receptor aggregation → mast-cell activation → histamine/lipid mediators/cytokines → symptoms + eosinophil recruitment.

Early vs late

Early Type I: minutes, preformed mast-cell mediators.
Late Type I: hours, inflammatory response.
Do NOT confuse late-phase Type I with Type IV DTH.

II vs III: II antibody binds the target directly. III complexes form in circulation first.

Type III - immune complexes

PatternRecognition
ArthusLocal; preformed IgG; local IC deposition/complement. Example: sore arm hours after dT booster.
Serum sicknessSystemic; foreign antigen; rash + GN + arthritis + fever as antibody forms, usually ~1 week.
Hypersensitivity pneumonitisInhaled antigen → IgG → IC deposition in alveoli; farmer's lung / bird fancier's lung.
Common deposition outcomes: glomerulus → nephritis; synovium → arthritis; postcapillary venules → vasculitis.

Type IV - T cells

  • Usually 1-3 days after antigen contact.
  • Th1 + macrophage inflammatory pathway; processed antigen presented by MHC II.
  • Can also be cytotoxic T-cell mediated.
  • DTH = detrimental delayed hypersensitivity; CMI = beneficial cell-mediated immunity.
  • Examples: contact dermatitis, transplant rejection, fungal resistance, Hashimoto thyroiditis.
