Qualitative vs quantitative

HbS/C/E: structural variants, usually missense.

Thal: decreased/absent chain synthesis.

  • Alpha-thal: usually deletions.
  • Beta-thal: promoter/splice/nonsense/frameshift etc.
  • beta+ reduced; beta0 absent.

Sickle cell - mutation to complication

FactMust know
Mutationbeta6 Glu -> Val; GAG -> GTG
MechanismDeoxy HbS polymerizes -> rigid RBCs -> vaso-occlusion + membrane damage/hemolysis.
Promotes sicklingHypoxia, acidosis, dehydration / high MCHC.
ProtectiveHbF (and HbA) inhibits polymerization.
Vaso-occlusive cluesPain, dactylitis, ACS, stroke, AVN, priapism, nephropathy.
Hemolysis cluesChronic anemia, retics, bilirubin/gallstones, NO scavenging/endothelial dysfunction.
Classic associationsFunctional asplenia -> encapsulated infection; Salmonella osteomyelitis; parvovirus B19 aplastic crisis.

Structural variants

HbS: beta6 Glu->Val; polymerizes.

HbC: beta6 Glu->Lys; mild hemolysis/splenomegaly; crystals.

HbE: beta26 Glu->Lys; Southeast Asia; structural variant + mild beta-thal effect via altered splicing.

Hb analysis fast rules

  • AS trait: A > S.
  • SS: no A; S dominant.
  • SC: S + C; no A.
  • beta-thal trait: A dominant + high A2.
  • beta-thal major: high F, very low/absent A.
  • alpha-thal trait: adult electrophoresis may look normal.

Beta-thal phenotype

FormKey findings
Trait/minorHeterozygous; mild/asymptomatic microcytic anemia; HbA2 elevated (~5% on slide); mild HbF increase possible.
IntermediaModerate anemia; variable transfusion; hepatosplenomegaly, skeletal changes, extramedullary hematopoiesis.
MajorSevere early transfusion dependence; excess alpha chains -> ineffective erythropoiesis + hemolysis; marrow expansion; growth/bone changes; iron overload.

Why beta-thal hurts marrow

Unpaired alpha chains are insoluble -> precipitate in erythroid precursors -> apoptosis/ineffective erythropoiesis. Severe anemia -> EPO -> marrow expansion + extramedullary hematopoiesis.

Iron overload

Comes from transfusions + increased intestinal absorption driven by ineffective erythropoiesis/hepcidin suppression.

If you see X -> think Y

  • Microcytosis + high HbA2 -> beta-thal trait.
  • Newborn initially well, later SCD symptoms as HbF falls -> gamma-to-beta switch.
  • S + C with no A -> HbSC disease.
  • Four alpha deletions + fetal hydrops -> Hb Barts (gamma4).
  • Three alpha deletions -> HbH (beta4).
  • Severe anemia + maxillary/skull expansion -> ineffective erythropoiesis / marrow expansion.
  • CRISPR target BCL11A enhancer -> reactivate gamma globin / HbF, not direct HbS correction.
Last 5 minutes: A=alpha2beta2, A2=alpha2delta2, F=alpha2gamma2. S=Glu6Val, C=Glu6Lys, E=Glu26Lys. Alpha deletion count: 1 silent, 2 trait, 3 HbH beta4, 4 Barts gamma4. Beta trait = high A2. HbF protects SCD and beta-thal.
