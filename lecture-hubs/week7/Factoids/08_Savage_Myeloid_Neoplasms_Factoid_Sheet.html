Myeloid Neoplasms - Factoid Sheet

Week 7 Hematology • Lecture 8 • Savage • memorize-first companion
ScholarRx: Chronic Myeloproliferative Disorders • AML • CML • PV
Core framework: AML = immature blasts • MDS = ineffective/dysplastic production • MPN = too many mature cells • MDS/MPN = dysplasia + proliferation.

AML / APL

FactoidMemorize
AMLUsually >=20% myeloid blasts unless a defining genetic lesion allows diagnosis below threshold.
Auer rodDefinitive myeloid lineage clue.
Marrow failureAnemia -> fatigue; thrombocytopenia -> bleeding; neutropenia -> infection.
t(8;21)Favorable recurrent AML association in lecture.
inv(16)Favorable; abnormal eosinophils / myelomonocytic disease.
APLt(15;17) PML-RARA + abnormal promyelocytes/Auer rods + DIC.
APL actionStart ATRA immediately when suspected - do not wait for FISH.
Differentiation syndromeFever, edema/weight gain, dyspnea/pulmonary edema, hypotension, rising WBC -> dexamethasone.

MDS

  • Hypercellular marrow + peripheral cytopenias
  • Ineffective hematopoiesis / dysplasia
  • Pseudo-Pelger-Huet neutrophils
  • Micromegakaryocytes
  • Ring sideroblasts
  • Can progress to AML

Classification trap

The official LO is conceptual. Savage marks detailed MDS WHO/ICC tables “No need to memorize.” Learn recurring fingerprints, not every category.

CML

t(9;22) Philadelphia -> BCR-ABL1 constitutive tyrosine kinase -> leukocytosis + full myeloid left shift + basophilia + low LAP -> TKI.
ClueMeaning
BasophiliaStrongly favors CML over simple leukemoid reaction.
Low LAPCML; reactive leukemoid response tends to have high LAP.
FISH/karyotypeDetect BCR-ABL1 / Philadelphia chromosome.
PCRQuantitative molecular monitoring after diagnosis.
ImatinibBinds BCR-ABL kinase and blocks phosphorylation/downstream signaling.

PV clues

  • Low EPO = autonomous production
  • Secondary erythrocytosis tends to have high EPO
  • Hot-shower itching
  • Hyperviscosity / thrombosis
  • Erythromelalgia

ET paradox

  • Many platelets can clot
  • But extreme thrombocytosis can cause acquired vWD and bleeding
  • Rule out reactive thrombocytosis

PMF mechanism

Abnormal megakaryocytes release fibroblast-stimulating cytokines -> reactive marrow fibrosis -> dry tap + myelophthisic smear + extramedullary hematopoiesis -> huge spleen.

If you see X -> think Y

  • Multiple Auer rods + bleeding/DIC -> APL
  • Busy marrow + cytopenias + pseudo-Pelger -> MDS
  • WBC 150K + basophilia + myelocytes -> CML
  • High Hct + low EPO + itching after shower -> PV
  • Platelets >450K + staghorn megakaryocytes -> ET
  • Teardrops + dry tap + massive spleen -> PMF
  • Persistent monocytosis + dysplasia + BCR-ABL1 negative -> CMML
Last 5 minutes: APL=15;17 PML-RARA/DIC/ATRA. CML=9;22 BCR-ABL1/basophilia/low LAP/TKI. PV=JAK2/high Hct/low EPO. ET=JAK2-CALR-MPL/platelets. PMF=JAK2-CALR-MPL/teardrop/dry tap/spleen.
