Precursor / Hodgkin essentials

DiseaseCold facts
B-ALL/LBLChild; marrow/blood; TdT+, CD34+, CD19+, CD10+; t(12;21) favorable in deck, t(9;22) unfavorable.
T-ALL/LBLTeen male + mediastinal/thymic mass; TdT+, CD3/CD7+.
Classic HodgkinRS/owl-eye; CD15+, CD30+, CD45-; contiguous nodal spread; often above diaphragm.
NLPHLPopcorn/L&H cells; CD20+, CD45+, CD15-/CD30-; indolent.

Diagnostic tools

  • IHC: markers in tissue + architecture
  • Flow: co-expression/clonality in cell suspension
  • FISH: rearrangements/copy number
  • Light-chain restriction: monoclonality clue

HL vs NHL

  • HL: contiguous spread, RS cells, extranodal less common
  • NHL: often multicentric/disseminated, extranodal common

T-cell + Plasma Cell + Vignette Factoids

MF / Sézary

  • Cutaneous CD4 T-cell lymphoma
  • Pautrier microabscess
  • Cerebriform nuclei
  • CD3+, CD4+, CD7 loss
  • Sézary = erythroderma + blood involvement

Plasma-cell phenotype

  • CD138+, clonal immunoglobulin
  • M-spike / paraprotein
  • Rouleaux
  • Lytic lesions
  • Normal Ig suppressed -> infections

MGUS vs smoldering vs active myeloma

StateCore logic
MGUSLow clonal burden; M-protein may be present; no myeloma-defining event; classic companion threshold <10% marrow plasma cells.
SmolderingHigher clonal burden than MGUS but no myeloma-defining event.
Active myelomaClonal plasma cells/plasmacytoma + CRAB or SLiM myeloma-defining event.
CRAB: hyperCalcemia • Renal injury • Anemia • Bone lesions.
SLiM enrichment: ≥60% marrow plasma cells • FLC ratio ≥100 (involved FLC ≥100 mg/L) • ≥2 MRI focal lesions.

AL amyloid

Monoclonal light-chain protein deposits in tissues. Think nephrotic syndrome, restrictive cardiomyopathy, macroglossia, periorbital purpura. Congo red -> apple-green birefringence.

If you see X -> think Y

  • TdT+ child + pancytopenia -> B-ALL
  • TdT+ teen + mediastinal mass -> T-ALL/LBL
  • CD15/30 + lacunar cells/fibrous bands -> nodular sclerosis HL
  • CD5+ CD23+ + smudge -> CLL
  • CD5+ CD23- cyclin D1+ -> mantle
  • t(14;18) + painless nodes -> follicular
  • H. pylori + gastric lymphoid mass -> MALT
  • Rapid mass + large B cells -> DLBCL
  • t(8;14) + starry sky -> Burkitt
  • Back pain + M-spike + lytic lesions -> myeloma
Last 5 minutes: TdT=blast. Classic HL=CD15/30. CLL=5+23+. Mantle=5+23-, cyclin D1, 11;14. Follicular=14;18 BCL2. Burkitt=8;14 MYC. MF=Pautrier. Myeloma=CRAB/SLiM + monoclonal plasma cells.
