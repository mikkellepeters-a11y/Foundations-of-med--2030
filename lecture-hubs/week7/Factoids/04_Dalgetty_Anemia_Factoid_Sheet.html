Algorithm cold: Low Hb -> CBC/diff -> retic (marrow response?) -> MCV -> smear + targeted labs -> identify the cause.

RBC indices

  • MCV: <80 micro, 80-100 normo, >100 macro.
  • RDW: size variation; often high in IDA.
  • Retic: high = loss/destruction if marrow intact; low/inadequate = production problem.
  • A "normal" retic % during anemia can be inappropriately low.

Hepcidin

Hepcidin binds/degrades ferroportin.

  • High hepcidin -> less gut iron absorption.
  • High hepcidin -> macrophages retain iron.
  • Inflammation -> high hepcidin -> functional iron restriction.

IDA associations

  • Ice craving/pica
  • Restless legs
  • Koilonychia
  • Plummer-Vinson = IDA + esophageal web/dysphagia
  • Always find source: menses, GI, pregnancy, GU, malabsorption, donation, parasite

Sideroblastic / lead

  • Prussian blue ring sideroblasts.
  • Acquired: alcohol, MDS, copper deficiency; B6-responsive subset.
  • Lead: abdominal colic + neuropathy + basophilic stippling + Burton line.
  • Lead inhibits ALA dehydratase + ferrochelatase.

Pernicious anemia

Autoimmune intrinsic-factor/parietal-cell problem -> B12 malabsorption.

  • Chronic atrophic gastritis
  • Other autoimmune disease association
  • Increased gastric carcinoma risk
  • Parenteral or sufficiently high-dose oral B12 can treat
Do not mask B12 deficiency: folate alone can improve the anemia while neurologic injury continues.

If you see X -> think Y

  • Ice craving + spoon nails -> IDA
  • Low Fe + high ferritin + low TIBC -> inflammation
  • CKD + low retic -> inadequate EPO
  • Jaundice + acute Hb fall -> order LDH/haptoglobin/bilirubin + smear
  • Macrocytes + hypersegmented neutrophils -> megaloblastic
  • High MMA + neuro signs -> B12 deficiency
  • Basophilic stippling + abdominal/neuro symptoms -> lead
  • Ring sideroblasts -> sideroblastic anemia

Last 5 minutes: Retic tells production vs loss/destruction. MCV narrows morphology. IDA ferritin down/TIBC up; inflammation ferritin up/TIBC down. B12 = MMA up + neuro. Folate = MMA normal. Lead = stippling. Sideroblastic = ringed marrow iron.
